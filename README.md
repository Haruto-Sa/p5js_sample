# テトリスゲーム

HTML、CSS、JavaScriptおよびp5.jsライブラリを使用して実装されたクラシックなテトリスゲームです。

## 遊び方

-   **左矢印キー:** 落下中のブロックを左に移動します。
-   **右矢印キー:** 落下中のブロックを右に移動します。
-   **上矢印キー:** 落下中のブロックを回転させます。
-   **下矢印キー:** 落下中のブロックの速度を上げます。
-   **スペースバー:** ブロックを即座に一番下までドロップします。
-   **シフトキー:** 現在のブロックをホールドします（各ブロックにつき一度使用可能）。

## 機能

-   クラシックなテトリスゲームプレイ。
-   スコアリングシステム：ラインを消すごとに100ポイント。
-   ハイスコアトラッキング（ブラウザのローカルストレージに保存）。
-   後で使用するためにブロックを保存する「ホールド」機能。
-   難易度の上昇：30秒ごとに落下ブロックの速度が上がります。
-   ブロック着地、ライン消去、ゲームオーバー時の効果音。
-   ミュート/アンミュートオプション付きの背景音楽。
-   シンプルな背景オーディオビジュアライザー。
-   スタート画面、ゲーム画面、ゲームオーバー画面。

## 使用技術

-   HTML5
-   CSS3
-   JavaScript (ES6)
-   p5.js (グラフィックおよびサウンド用)

## 実行方法

1.  このリポジトリをクローンするか、ファイルをダウンロードします。
2.  ウェブブラウザで `index.html` ファイルを開きます。
3.  「Start Game」ボタンをクリックして開始します。
